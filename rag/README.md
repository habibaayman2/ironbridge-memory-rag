\# rag/ — Retrieval Architecture (Person 3)



\## What's in here



| File | Purpose |

|---|---|

| `sync\_policies.py` | Copies the policy markdown files from `mcp\_server/` (the authoritative source, also exposed as MCP resources) into `rag/policies/`. Run this whenever a source policy changes, rather than copy-pasting manually. |

| `policies/` | The RAG corpus snapshot: the three IronBridge safety/procurement policy documents, split by `##` section headers via LangChain's `MarkdownHeaderTextSplitter`, with a `RecursiveCharacterTextSplitter` fallback for any section that exceeds \~500 characters. |

| `chunking.py` | `get\_policy\_chunks()` — reads every file in `policies/`, splits it into section-based chunks, and attaches `source` (filename) as metadata to each chunk. |

| `vector\_store.py` | `setup\_vector\_store()` — embeds every chunk with FastEmbed (`BAAI/bge-small-en-v1.5`, local, no API key required), stores them in a local Qdrant collection (`ironbridge\_policies`), and creates an explicit payload index on `metadata.source` so filtering happens during search, not after. |

| `test\_search.py` | Demonstrates a filtered similarity search: querying `ironbridge\_policies` for a question while restricting results to a single source document via a Qdrant `Filter`. |



\## Design decisions



\- \*\*Embeddings: FastEmbed, not an external API.\*\* Runs fully locally, no

&#x20; `OPENAI\_API\_KEY` needed, no per-query cost. Given the small size of the

&#x20; current corpus (3 short policy docs), a local embedding model is more

&#x20; than accurate enough and keeps the setup dependency-free for teammates.

\- \*\*Chunking: section-based, not fixed-size.\*\* Each policy document is

&#x20; short (\~150–200 words), so a fixed 300–500 word window would produce a

&#x20; single chunk per document. Splitting on `##` headers instead gives

&#x20; smaller, topically focused chunks, and each section's title becomes

&#x20; usable metadata.

\- \*\*`rag/policies/` is a generated snapshot, not a second source of

&#x20; truth.\*\* `mcp\_server/\*.md` remains authoritative (it's what the MCP

&#x20; server exposes as resources). `sync\_policies.py` copies from there so

&#x20; the RAG pipeline never silently drifts from what the agent's resources

&#x20; actually say.

\- \*\*Local Qdrant storage (`rag/local\_qdrant/`) is gitignored.\*\* It's

&#x20; regenerated by running `python -m rag.vector\_store`; committing the

&#x20; binary index files would bloat the repo for no benefit.



\## Setup



```bash

pip install -r rag/requirements.txt

python rag/sync\_policies.py      # refresh rag/policies/ from mcp\_server/

python -m rag.vector\_store       # build/rebuild the local Qdrant index

python rag/test\_search.py        # sanity-check filtered similarity search

```
